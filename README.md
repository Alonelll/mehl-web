# Mehl Fabrik – Website

Website der Mehl Fabrik in Rotenburg (Wümme): handgemachte Pizza, Pasta und Baguettes aus dem Steinofen.

| Ordner | Inhalt |
| --- | --- |
| [`web/`](web/) | Die Website: React 19, TypeScript, Tailwind CSS 4, Vite, vorgerendertes HTML. Details und Pflegehinweise in [`web/README.md`](web/README.md). |
| [`project/`](project/) | Design-Prototyp aus Claude Design (HTML), nach dem die Website 1:1 umgesetzt ist. Referenz, wird nicht ausgeliefert. |

## Schnellstart

```bash
cd web
npm install
npm run dev      # Entwicklung → http://localhost:5173
npm run build    # statische Seite in web/dist/
```
